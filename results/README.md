# Benchmark data

The [benchmark guide](../docs/research/benchmarks.md) lists outcomes and replay commands. Each batch audit directory contains the saved predictions and the design or plan used to select labels.

`course/` contains saved IMDb, Jigsaw and FEVER predictions. `monitoring/` contains chronological Omni-MATH splits for the [monitoring example](../docs/guide/monitor.md). For earlier scoring experiments, including the black-box comparisons, use the matching tagged data and scripts. [Research archive](https://github.com/Daveyuwang/caat/tree/v1.1.2/results)
